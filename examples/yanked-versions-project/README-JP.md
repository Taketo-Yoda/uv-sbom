# yanked-versions-project

`uv-sbom` の `--check-yanked` 機能をデモするためのサンプルプロジェクトです。
PyPI で **取り下げ（yanked）されたバージョン** をピン留めしています。

## 目的

`--check-yanked` はロックされた各バージョンの取り下げ状態を PyPI に問い合わせます。
通常のプロジェクトでは取り下げされていないバージョンをピン留めしているため、チェック結果は空になります。

このプロジェクトは `requests==2.32.0`（CVE-2024-35195 対策との競合により取り下げ済み）を
ピン留めしているため、`--check-yanked` を実行すると常に非空の結果が得られます。

> :warning: このバージョンは本番環境で使用しないでください。

## 使い方

```bash
# リポジトリルートから実行
uv-sbom -p examples/yanked-versions-project --check-yanked --no-check-cve -f markdown
```

**期待される「取り下げ済みパッケージ」セクション:**

```markdown
## 取り下げ済みパッケージ

ロックされたバージョンがPyPIから取り下げられたパッケージです。取り下げは通常、重大なバグ、セキュリティ上の問題、または誤った公開を示しています。取り下げられていないバージョンに更新してください。

| パッケージ | バージョン | 種別 | 理由 | 状態 |
|-------|-------|----|----|----|
| requests | 2.32.0 | 直接依存パッケージ | Yanked due to conflicts with CVE-2024-35195 mitigation | ⚠️ |
```

取り下げ済みパッケージが検出されたため、終了コードは **1** になります。
